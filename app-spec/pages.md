# Pages and Routes

## `/`
Landing page.

Sections:

- Hero: “Every story has another side.”
- Short explanation
- Three mode previews
- Example disputes
- Trust/neutrality principles
- CTA: “Try a story”

## `/app`
Main input page.

Components:

- Paste area
- URL/text toggle, optional
- Mode selector
- Source strictness selector
- Submit button
- Example chips

## `/result/[id]`
Result report page.

Components:

- Report header
- Detected story summary
- Other side report
- Evidence/source notes
- Copy/export buttons
- Regenerate controls

## `/library`
Saved reports page, optional for MVP.

## `/about`
Explains neutrality policy.

## `/examples`
Public examples. Use safe, non-defamatory, well-known historical/business cases.
