# Web Research Policy

For current events and niche disputes, the app should use web research before generating the final report.

## Preferred source order

1. Official statements from involved parties
2. Court filings or regulatory documents
3. Primary documents, letters, speeches, records
4. Reputable reporting
5. Expert analysis
6. Social media posts, only if directly relevant

## Source handling

The AI should never fabricate sources. If no source is available, it should say:

> No direct source was found for this side in the available research. The following is a cautious possible counter-position, not a sourced claim.

## Source strength labels

- Strong: official document, court filing, primary source
- Medium: reputable reporting or expert analysis
- Weak: indirect commentary or unsourced public claim
- Missing: no usable source found
